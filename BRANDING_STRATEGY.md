## The Interlinking Strategy

### Why Interlink?

1. **SEO Benefits**
   - Pass link authority between sites
   - Increase dwell time (users explore both sites)
   - Create topical authority cluster
   - Earn backlinks more easily with diverse content

2. **User Journey Optimization**
   - Game fans discover your other work
   - Portfolio visitors find the game
   - Maximize conversion opportunities
   - Build comprehensive narrative

3. **Brand Cohesion**
   - Reinforce the "Elliot Telford Universe"
   - Show depth of expertise
   - Create multiple touchpoints

### How to Interlink (Already Implemented)

**From elliottelford.com → exploretheuniverse2175.com:**
- ✅ Prominent nav button: "Play the Game" (special styling, always visible)
- ✅ Cross-site promo banner (between Featured Work and Blog Posts)
- 🔄 Game section on homepage (links to game site)
- 🔄 Blog posts about game development (natural contextual links)
- 🔄 Footer link to game website

**From exploretheuniverse2175.com → elliottelford.com:**
- 🔄 "About the Developer" section (links to portfolio)
- 🔄 "More Simulations" link (to your simulation gallery)
- 🔄 Blog/Devlog links back to main blog
- 🔄 Footer author bio with link
