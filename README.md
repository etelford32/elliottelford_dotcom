# elliottelford.com

> Building the future through code & physics

Personal website showcasing interactive astrophysics simulations, game development, and professional services.

## 🚀 Overview

This site features:

- **Interactive Astrophysics Simulations** - Scientifically accurate 3D visualizations with Three.js
- **Game Development** - "Explore the Universe 2175" space RTS game showcase
- **Portfolio & Blog** - Technical projects and insights
- **Professional Services** - Game development, astrophysics consulting, systems engineering

## 🛠️ Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS v4
- Three.js / React Three Fiber
- Framer Motion
- MDX for blog content

## 💻 Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Visit [http://localhost:3000](http://localhost:3000) to see the site.

## 📁 Structure

```
app/          # Next.js pages & routes
components/   # React components
lib/          # Utilities & constants
content/      # MDX blog posts & data
public/       # Static assets
```
